Edge AI: Engineering Local Image Classification on Android

Created on October 20, 2023

2023   ·   android   java   tflite   python   iit-bombay   edge-ai   ·   Android   Machine-Learning

During my 4th year as an undergraduate student at IIT Bombay, I wanted to move beyond theoretical machine learning frameworks and tackle real-world mobile engineering constraints. This drive led me to join the SPANN Lab under the guidance of Prof. V.M. Gadre as an Android Developer through the iSURP IITB initiative.

My core objective was clear: bridge the gap between heavy machine learning models and mobile deployment architectures. I needed to build a production-ready application from scratch that could execute intelligent vision systems locally, completely bypassing the need for high-latency, cloud-based infrastructure.

The Challenge: Breaking Free from Cloud Latency

Traditional mobile applications typically offload computer vision tasks to remote servers via API endpoints. While this saves device memory, it introduces significant latency and makes the app completely dependent on continuous network connectivity.

To achieve zero-latency, on-device intelligence (Edge AI), the machine learning model had to run natively within the client environment on a standard smartphone chip. The real engineering bottleneck was figuring out how to execute this without draining the hardware’s resources or causing the UI to freeze during inference.

The Architecture: Bridging Java and Python

I started the pipeline by wireframing a modern, intuitive user interface in Figma to cleanly present the analytical data. Once the design system was locked in, I transitioned to Android Studio to build the core application framework using Java.

To solve the localized inference problem, I engineered a hybrid runtime architecture:

  • The Bridge: I integrated the Chaquopy SDK, a robust toolkit that allows seamless script execution and bidirectional communication between Java-based Android components and localized Python environments.
  • The Engine: Within the Python layer, I utilized the TensorFlow Lite (TFLite) module to load highly compressed, pre-trained image classification models optimized for mobile.
  • The Pipeline: I built a custom bitmap conversion pipeline. The Java frontend captured live camera frames, optimized their dimensions, and passed the raw byte arrays across the SDK bridge. The Python backend instantly processed the frames, executed the TFLite inference, and smoothly returned the classification tokens back to the UI.

The Result: Real-Time Edge Intelligence

The months spent refining this memory-conscious architecture paid off. I successfully delivered a highly optimized, fully functional system capable of real-time local image classification.

This project proved that hardware constraints on edge devices can be overcome with smart, cross-language software design. Beyond the technical milestones, this journey in full-stack mobile AI engineering was highly rewarding, capping off with a personal Letter of Recommendation from Prof. Gadre validating the rigorous approach.
